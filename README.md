TII Project Tracker - Vite + React + Tailwind (Local-only)

How to run locally:
1. Install Node.js (recommended v18+)
2. In project folder:
   npm install
   npm run dev

Build:
   npm run build
   npm run preview

Notes:
- Projects are stored in localStorage.
- Login credentials are in src/App.jsx (defaultUsers).
- Resources are protected for team members: viewable, links clickable, not copyable.
- To deploy to GitHub Pages: build and follow GitHub Pages deployment for Vite apps (or use gh-pages).
